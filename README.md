# 🌐 Divya Portfolio

A modern, fully responsive developer portfolio built to showcase my skills, projects, journey, and experience as a Full Stack Developer.

Designed with smooth animations, glassmorphism UI, dark mode, and an interactive user experience to create a professional online presence.

---

## 🚀 Features

- 🏠 Beautiful Hero Section
- 👩 About Me
- 💻 Skills Showcase
- 📈 Learning Journey Timeline
- 🚀 Featured Projects
- 🖼 Interactive Project Gallery
- 🌙 Dark & Light Mode
- 📱 Fully Responsive Design
- ⚡ Smooth Framer Motion Animations
- 📄 Resume Download
- 📬 Contact Form using EmailJS
- 🔥 Modern Glassmorphism UI
- 🎨 Clean & Minimal Design

---

## 🧠 How It Works

- Visitors can learn about my background and career journey.
- Explore my technical skills and technologies.
- View detailed information about my featured projects.
- Open project galleries with screenshots.
- Download my resume directly.
- Contact me through the integrated EmailJS contact form.
- Enjoy a fully responsive experience across desktop, tablet, and mobile devices.

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/divya-portfolio.git
```

Go to the project directory

```bash
cd divya-portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

---

## 🌐 Environment Variables

Create a `.env` file in the project root and add:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```
